# LuckySpeeder - GitHub Actions 云编译

## 使用方法

1. Fork 此仓库
2. 进入仓库的 **Actions** 标签页
3. 点击 **IOS Build** workflow，点击 **Run workflow** 按钮
4. 等待编译完成后，下载 Artifacts 中的 `LuckySpeeder.dylib`

## 支持的编译目标

- `arm64-apple-ios` - iOS 设备（推荐）
- `arm64-apple-ios-macabi` - Mac Catalyst
- `arm64-apple-xros` - visionOS
- `arm64-apple-tvos` - Apple TV
